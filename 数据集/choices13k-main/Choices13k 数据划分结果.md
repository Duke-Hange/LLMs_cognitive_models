## 策略 1: Problem-Split（问题划分）

### 🎯 划分目标
测试模型对未见问题的泛化能力，验证模型是否真正理解了决策规律而非死记硬背。

### 📊 划分方式
- **方法**: 随机选择 80% 的问题作为训练集，20% 作为测试集
- **随机种子**: 42
- **划分单位**: 问题ID（Problem）

### 📈 划分结果

| 数据集 | 记录数 | 问题数 | 占比 |
|--------|--------|--------|------|
| **训练集** | 11,676 | 10,404 | 80.0% |
| **测试集** | 2,892 | 2,602 | 20.0% |
| **总计** | 14,568 | 13,006 | 100% |

### 📝 详细说明
- 训练集包含 10,404 个不同的问题
- 测试集包含 2,602 个不同的问题
- 训练集和测试集的问题ID互不重叠
- 每个问题可能有多条记录（不同反馈条件、区块等）

### 📁 文件位置
- 训练集: `strategy1_problem_split/train.csv`
- 测试集: `strategy1_problem_split/test.csv`
- 划分信息: `strategy1_problem_split/split_info.json`

## 策略 2: Feedback-Split（反馈条件划分）⭐ **最重要**

### 🎯 划分目标
测试模型是否真正理解反馈机制，能否从"有反馈"条件迁移到"无反馈"条件。这是区分"真正理解"和"死记硬背"的关键测试。

### 📊 划分方式
- **方法**: 按反馈条件（Feedback）划分
- **训练集**: 所有有反馈的问题（Feedback = True）
- **测试集**: 所有无反馈的问题（Feedback = False）

### 📈 划分结果

| 数据集 | 记录数 | 问题数 | 占比 |
|--------|--------|--------|------|
| **训练集** (有反馈) | 12,188 | - | 83.7% |
| **测试集** (无反馈) | 2,380 | - | 16.3% |
| **总计** | 14,568 | - | 100% |

### 📝 详细说明
- **训练集**: 包含所有有反馈条件的记录，被试选择后能看到实际获得的奖励
- **测试集**: 包含所有无反馈条件的记录，被试选择后不会看到实际结果
- **数据不平衡**: 有反馈的数据远多于无反馈的数据（约 5:1）
- **科学意义**: 测试模型是否理解"决策从经验"（Decisions from Experience）vs "决策从描述"（Decisions from Description）的差异

### 📁 文件位置
- 训练集: `strategy2_feedback_split/train.csv`
- 测试集: `strategy2_feedback_split/test.csv`
- 划分信息: `strategy2_feedback_split/split_info.json`

## 策略 3: Parameter-Split（参数空间划分）

### 🎯 划分目标
测试模型对问题参数空间的抽象能力，验证模型是否捕捉了决策的深层规律而非表面模式。

### 📊 划分方式
- **方法**: 按期望值差异（EV_diff）划分
- **划分参数**: |EV_diff|（期望值差异的绝对值）
- **阈值**: 3.4（中位数）
- **训练集**: |EV_diff| < 3.4（期望值差异小的问题）
- **测试集**: |EV_diff| >= 3.4（期望值差异大的问题）

### 📈 划分结果

| 数据集 | 记录数 | 问题数 | 占比 |
|--------|--------|--------|------|
| **训练集** (|EV_diff| < 3.4) | 7,246 | - | 49.7% |
| **测试集** (|EV_diff| >= 3.4) | 7,322 | - | 50.3% |
| **总计** | 14,568 | - | 100% |

### 📝 详细说明
- **EV_diff 计算**: EV_diff = EV_B - EV_A
  - EV_A = pHa × Ha + (1-pHa) × La
  - EV_B = pHb × Hb + (1-pHb) × Lb
- **阈值选择**: 使用中位数（3.4）作为划分阈值，确保训练集和测试集大小接近
- **科学意义**: 测试模型是否理解了期望值差异如何影响选择，能否将规律推广到不同的参数空间

### 📁 文件位置
- 训练集: `strategy3_parameter_split/train.csv`
- 测试集: `strategy3_parameter_split/test.csv`
- 划分信息: `strategy3_parameter_split/split_info.json`

## 数据清洗报告

### 清洗方法
对所有三个策略的数据进行了统一的数据清洗，包括：
1. **缺失值检查**: 检查所有字段的缺失值
2. **有效性验证**: 
   - bRate 应在 [0, 1] 范围内
   - pHa, pHb 应在 [0, 1] 范围内
   - n (被试数量) 应 > 0
3. **异常值检测**: 使用 IQR 方法（3倍IQR）检测异常值（记录但未删除）
4. **重复值检查**: 检查并删除重复行

### 清洗结果

| 指标 | 数值 |
|------|------|
| **原始数据量** | 14,568 条 |
| **清洗后数据量** | 14,568 条 |
| **删除数据量** | 0 条 |
| **缺失值** | 无 |

### 异常值检测（已记录但未删除）

| 字段 | 异常值数量 | 说明 |
|------|-----------|------|
| Ha | 138 | Gamble A 的高收益值异常值 |
| bRate_std | 26 | 选择频率标准差异常值 |

**注意**: 异常值已记录但未删除，因为这些可能是有效的极端情况，反映了真实的数据分布。

## 使用建议

### 实验优先级

1. **策略2 (Feedback-Split)** ⭐⭐⭐
   - **最重要**: 这是核心实验，必须做
   - **科学价值**: 区分"真正理解"和"死记硬背"
   - **注意**: 数据不平衡，建议使用加权损失函数

2. **策略3 (Parameter-Split)** ⭐⭐
   - **重要**: 测试模型的抽象能力
   - **科学价值**: 验证模型是否捕捉了深层规律
   - **注意**: 训练集和测试集大小接近，适合对比实验

3. **策略1 (Problem-Split)** ⭐
   - **基础**: 作为基线实验
   - **科学价值**: 验证模型不是死记硬背
   - **注意**: 相对"宽松"的测试，适合初步验证

### 模型训练建议

1. **数据加载**: 直接从各策略文件夹的 `train.csv` 和 `test.csv` 加载数据
2. **特征工程**: 使用 `data_standardization.py` 中的 `Choices13kStandardizer` 进行特征提取
3. **评估指标**: 
   - MSE / RMSE
   - R²
   - 相关系数
   - 条件分布检查（按反馈条件、模糊性等分组）

### 注意事项

1. **数据不平衡** (策略2):
   - 有反馈数据远多于无反馈数据
   - 建议使用加权损失函数或分层采样

2. **参数空间差异** (策略3):
   - 训练集和测试集的参数分布不同
   - 需要验证模型是否真正理解了规律

3. **问题重叠**:
   - 策略1中训练集和测试集的问题ID互不重叠
   - 策略2和策略3中，同一问题可能同时出现在训练集和测试集（但条件不同）

## 文件说明

### CSV 文件格式

所有 `train.csv` 和 `test.csv` 文件包含以下列：

| 列名 | 类型 | 说明 |
|------|------|------|
| Problem | int | 问题ID |
| Feedback | bool | 是否有反馈 |
| n | int | 被试数量 |
| Block | int | 区块编号 |
| Ha, pHa, La | float | Gamble A 的参数 |
| Hb, pHb, Lb | float | Gamble B 的参数 |
| LotShapeB, LotNumB | int | Gamble B 的彩票形状和数量 |
| Amb | bool | 是否存在模糊性 |
| Corr | int | 相关性 (-1, 0, 1) |
| bRate | float | 选择 Gamble B 的频率 [0, 1] |
| bRate_std | float | bRate 的标准差 |

**策略3额外列**:
- EV_A, EV_B: 期望值
- EV_diff: 期望值差异

### JSON 文件格式

`split_info.json` 包含：
- `strategy`: 策略名称
- `train_size`, `test_size`: 数据量
- `train_problems`, `test_problems`: 问题ID列表
- `clean_report`: 数据清洗报告
- 其他策略特定的参数（如阈值、条件等）
