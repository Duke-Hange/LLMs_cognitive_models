## 快速开始

### 1. 安装依赖

```bash
pip install numpy pandas scipy scikit-learn torch matplotlib seaborn
```

### 2. 数据标准化

```python
from data_standardization import Choices13kStandardizer

# 初始化标准化器
standardizer = Choices13kStandardizer(
    selections_path='c13k_selections.csv',
    problems_path='c13k_problems.json'
)

# 标准化数据
standardized_data = standardizer.standardize_all(save_path='c13k_standardized.json')

# 获取特征矩阵和目标向量
X = standardizer.get_feature_matrix()
y = standardizer.get_target_vector()
```

### 3. 数据划分

```python
from data_standardization import create_splits
import pandas as pd

# 准备 DataFrame
df = pd.DataFrame([...])  # 从 standardized_data 构建

# Feedback-Split（推荐）
train_idx, test_idx = create_splits(df, split_type='feedback')

# 或 Problem-Split
train_idx, test_idx = create_splits(df, split_type='problem', test_size=0.2)

# 或 Parameter-Split
train_idx, test_idx = create_splits(df, split_type='parameter', threshold=5.0)
```

### 4. 训练模型

```python
from models import ExpectedUtilityModel, ProspectTheoryModel, NeuralModel

# 符号模型
eu_model = ExpectedUtilityModel()
eu_model.fit(X_train, y_train, contexts_train)

pt_model = ProspectTheoryModel()

# 神经网络
neural_model = NeuralModel(input_dim=X.shape[1], hidden_dim=64)
neural_model.fit(X_train, y_train, epochs=50)
```

### 5. 评估模型


## 主要调整点总结

### 1. 数据格式调整

**原格式（Psych-101）**：
- 个体试次级别数据
- 包含历史序列
- 每个被试的完整轨迹

**调整后（Choices13k）**：
- 聚合数据（bRate）
- 问题级别数据
- 群体选择频率

### 2. 划分策略调整

| 原策略 | 调整后策略 | 说明 |
|--------|-----------|------|
| Subject-Split | Feedback-Split | 测试反馈机制理解 |
| Task-Split | Parameter-Split | 测试参数空间泛化 |
| - | Problem-Split | 基础泛化测试 |
| - | Block-Split | 顺序效应测试 |

### 3. 模型调整

**符号模型**：
- 期望效用理论（EU）
- 前景理论（PT）
- 累积前景理论（CPT）

**神经网络**：
- 输入：特征向量（非序列）
- 输出：bRate（回归任务）
- 架构：MLP with Dropout

**LLM**：
- Prompt 设计：自然语言描述赌博选项
- Few-shot 学习：提供示例
- Fine-tuning：QLoRA 微调

### 4. 评估指标调整

**拟合优度**：
- MSE, RMSE, MAE
- R², Correlation
- Beta 分布 NLL

**生成式验证**：
- 分布匹配（Wasserstein, KS）
- 条件分布检查
- 参数空间分析

**RSA 分析**：
- 符号模型潜变量 vs 神经网络表征
- 符号模型潜变量 vs LLM 表征

## 关键注意事项

### 1. 数据限制

- **聚合数据**：无法进行个体级别的学习轨迹分析
- **无序列信息**：每个问题相对独立
- **任务单一**：只有风险决策任务

### 2. LLM 实现

`models.py` 中的 `LLMModel` 类是框架代码，需要根据实际使用的 LLM 调整：

- **使用 transformers**：需要实现实际的模型加载和推理
- **使用 OpenAI API**：需要实现 API 调用
- **使用本地模型**：需要实现模型加载和推理

### 3. 计算资源

- **神经网络**：CPU 或 GPU（推荐 GPU）
- **LLM**：需要 GPU，建议至少 16GB 显存（对于 8B 模型）

## 常见问题

### Q: 如何处理缺失值？

A: Choices13k 数据应该是完整的，但如果有缺失值，可以在 `data_standardization.py` 中添加处理逻辑。

### Q: 如何添加新的划分策略？

A: 在 `data_standardization.py` 的 `create_splits()` 函数中添加新的 `elif` 分支。

### Q: 如何调整模型超参数？

A: 在 `models.py` 中修改模型初始化参数，或使用网格搜索/贝叶斯优化。

### Q: 如何可视化结果？

A: `evaluation.py` 中已包含可视化函数，会自动保存到 `output_dir`。
