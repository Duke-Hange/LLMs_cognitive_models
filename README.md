## 一、项目背景与目标

### 🎯 项目目标

本项目旨在通过对比三种模型来解释人类风险决策行为：
- **对比三种模型**：符号模型、神经网络、大语言模型
- **解释人类行为**：看哪种模型最能解释人类的风险选择
- **机制探索**：探索 LLM 是否真的有类似人类的决策机制（如前景理论、损失厌恶等）
- **任务范围**：专注于风险选择任务，通过问题参数空间的多样性保持挑战性

### 💡 为什么选择 Choices13k？

**数据集优势**：
- **数据量大**：13,006 个风险选择问题（约 14,568 条选择记录）
- **参数丰富**：期望值、风险、模糊性、相关性等多种特征
- **标准化**：数据质量高，格式统一

---

## 二、数据集特点


1. **聚合数据**
   - 提供群体选择频率（bRate），而非个体选择
   - 每个问题有多个被试（平均约 16 人）
   - **优势**：可以分析群体决策模式
   - **挑战**：无法追踪个体学习轨迹

2. **问题独立**
   - 每个问题相对独立，没有明显的序列依赖
   - **优势**：可以专注于单个问题的决策机制
   - **挑战**：无法建模序列学习

3. **任务聚焦**
   - 专注于风险决策任务
   - **优势**：可以深入探索决策机制
   - **策略**：通过参数空间多样性保持挑战性

## 三、数据格式

### 3.1 数据格式定义

Choices13k 数据格式：
```python
{
    "problem_id": 1,
    "context": {
        "gamble_a": [[0.95, 26], [0.05, -1]],
        "gamble_b": [[0.95, 21], [0.05, 23]],
        "feedback": True
    },
    "action": {
        "bRate": 0.63,  # 63% 的人选择了 Gamble B
        "n_subjects": 15
    },
    "reward": {
        "expected_value_A": 24.55,
        "expected_value_B": 20.90
    }
}
```

**数据特点**：
- 提供群体选择频率（bRate），而非个体选择
- 每个问题相对独立，没有历史序列
- 包含丰富的问题特征（期望值、风险、模糊性等）

### 3.2 预测目标

- **预测目标**：预测**群体**在**每个问题**的**选择频率**（回归任务）
- **类比**：预测"100 个人中，有多少人会选择 Gamble B？"
- **输出**：bRate（0-1 之间的浮点数）

## 五、三层模型介绍

### 5.1 层级 1：符号模型（Symbolic Models）

#### 🎯 定位
**传统认知心理学模型，提供可解释的基准线**

#### 📚 包含模型

**1. 期望效用理论（Expected Utility Theory）**
- **原理**：选择期望值更高的选项
- **公式**：EU = Σ(概率 × 收益)
- **特点**：简单、可解释，但不符合人类行为

**2. 前景理论（Prospect Theory）**
- **原理**：考虑损失厌恶、概率权重
- **特点**：更符合人类行为，获得诺贝尔奖的理论
- **参数**：
  - `alpha`：风险厌恶系数
  - `lambda`：损失厌恶系数（通常 > 1，说明损失比收益更敏感）
  - `gamma`：概率权重函数参数

#### 💡 为什么需要符号模型？
- **基准线**：看看最简单的模型表现如何
- **可解释性**：每个参数都有心理学意义
- **对比**：如果神经网络/LLM 表现不如符号模型，说明可能有问题

#### 🔬 增强符号模型实验（已完成）
基于原始符号模型实验，我们完成了**增强符号模型实验**，主要改进：
- **多结果分布支持**：直接从JSON原始分布提取特征，解决CSV特征过度简化问题
- **丰富特征工程**：50+维增强特征（期望值、方差、偏度、峰度、熵、分位数等）
- **增强模型架构**：4种增强模型完全支持多结果分布计算
- **文件位置**：`experiments/01_symbolic_models_enhanced/`

### 5.2 层级 2：神经网络（Neural Networks）【已完成】

#### 📌 当前状态
**已完成。** 实验目录 `experiments/02_neural_models/` 已实现**两类**神经网络：Value-Based、Context-Dependent，使用与 01 一致的标准化数据（`c13k_enhanced_standardized.json`）与三种划分（problem / parameter_amb / parameter_ev_extreme）。支持多种子训练与报告生成；结果参与 `04_comparison` 的跨模型比较。详见 `experiments/02_neural_models/README.md`。以下架构与数学形式参考 Peterson et al. (2021, *Science*)。

#### 🎯 定位
**无语言先验的纯统计学习，强调拟合能力**。与符号模型不同，神经网络的 $f(\cdot)$ 不预设效用函数形式，允许概率与结果以任意非线性方式相互作用。

#### 🔄 与符号模型阶段一致：基于「完整选项」建模
与符号模型阶段一致，**神经网络也同时考虑所有选项**，而非把问题简化为“只有 A、B 两个选项”的摘要：
- **每个选项（赌局）** 由其 **完整结果分布** 表示：即该赌局内 **所有** 结果–概率对 $(x_1,p_1),\ldots,(x_k,p_k)$，不预先压缩为单一值或 Ha/pHa/La 等少数特征。
- 这样既包含选项 A 的**全部结果**，也包含选项 B 的**全部结果**；Choices13k 中 Gamble B 平均约 3.78 个结果、最多 9 个，需支持多结果分布。
- 实现上可与增强符号实验管道对接：使用从完整分布提取的 **50+ 维增强特征**，或对分布做编码（如每赌局一组 $(x,p)$ 向量 / 固定长度表示），保证与 `experiments/01_symbolic_models_enhanced/` 的数据口径一致。

#### 📐 两类模型概览

| 特征 | 基于价值的模型 (Value-Based) | 上下文依赖模型 (Context-Dependent) |
|------|------------------------------|-------------------------------------|
| **理论基础** | 广义效用理论 / 独立性假设 | 上下文交互理论 / 违反独立性 |
| **数学映射** | 输入 → 价值 $V$ → 概率 $P$ | 输入 → 选择概率 $P$（端到端） |
| **输入** | 单赌局**完整分布** $(x, p)$，分别算 $V(A)$、$V(B)$ | 两赌局**完整分布**并集 $(x_A, p_A, x_B, p_B)$ |
| **隐藏层** | 1 层，64 单元，Sigmoid | 2 层，每层 32 单元，Sigmoid |
| **输出目标** | 赌局价值 $V$，再经 Softmax 得 $P$ | 直接输出选择概率 $P(A)$ |
| **可解释性** | 较高（保留价值比较结构） | 较低（黑盒） |

**文献结论**：上下文依赖模型在预测上常优于基于价值的模型，提示人类风险决策会受备选项（Context）影响。

---

#### 🏗️ 模型一：基于价值的模型 (Value-Based)

**核心假设**：赌局价值仅依赖自身属性，独立于备选赌局。$V(A) = f(x_A, p_A)$，$f(\cdot)$ 为非线性函数近似器。此处 $x_A,\,p_A$ 表示**该赌局的完整结果与概率向量**（所有选项/结果），非摘要。

**架构**：
```
输入层：单赌局完整分布 (x, p) — 该赌局内所有结果及其概率
  ↓
隐藏层 1：64 单元，Sigmoid
  ↓
输出层：1 个线性单元 → 标量价值 V
```
对 Gamble A、B 分别前向得到 $V(A)$、$V(B)$，再经 **Softmax** 得到选择概率：
$$P(A) = \frac{e^{\eta V(A)}}{e^{\eta V(A)} + e^{\eta V(B)}}$$
其中 $\eta$ 为温度参数，控制决策确定性程度。

---

#### 🏗️ 模型二：上下文依赖模型 (Context-Dependent)

**核心假设**：选择概率由两个赌局的**全部**信息共同决定，允许“上下文效应”。$P(A) = g(x_A, p_A, x_B, p_B)$。此处 $x_A,p_A$ 与 $x_B,p_B$ 均为**各自赌局的完整结果分布**（所有结果），非摘要。

**架构**：
```
输入层：两赌局完整分布拼接 (x_A, p_A, x_B, p_B) — 每个赌局的所有结果及其概率
  ↓
隐藏层 1：32 单元，Sigmoid
  ↓
隐藏层 2：32 单元，Sigmoid
  ↓
输出层：1 个单元，Sigmoid → 选择概率 P(A)（或 P(B)=1-P(A)）
```

---

#### 📊 输入特征（与 Choices13k 对接）

- **与符号模型阶段一致**：每个赌局用**完整结果分布**作为输入（所有结果–概率对），不简化为“仅 A、B 两个选项”的少数特征（如 Ha/pHa/La、Hb/pHb/Lb）。
- **可选实现方式**：
  - **增强特征**：使用 `experiments/01_symbolic_models_enhanced/` 的 50+ 维增强特征（从完整分布提取的 EV、方差、偏度、峰度、熵、分位数等），与符号模型管道一致。
  - **分布编码**：直接对每个赌局的 $(x_1,p_1),\ldots,(x_k,p_k)$ 做固定长度编码（如 padding 到最大结果数、或每赌局一组向量），以支持多结果赌局（Choices13k 中 B 平均约 3.78 个结果，最多 9 个）。
- **预测目标**：bRate（选择 Gamble B 的概率），回归任务，输出约束在 [0, 1]。

## 六、评估方法

### 6.1 拟合优度（Goodness-of-Fit）

**问题**：模型预测得准不准？

**指标**：
- **MSE/RMSE**：预测值与真实值的差异
- **R²**：模型解释的方差比例
- **Correlation**：预测值与真实值的相关性
- **Beta NLL**：考虑被试数量的负对数似然

**解读**：
- R² > 0.8：很好
- R² > 0.6：不错
- R² < 0.4：较差

### 6.2 生成式验证（Generative Checks）

**问题**：模型生成的数据像不像人类数据？

**方法**：
1. **分布匹配**：比较真实分布和模型生成分布
2. **条件分布检查**：按反馈条件、模糊性等分组检查
3. **参数空间分析**：看模型在不同参数空间的行为

**解读**：
- 如果模型生成的分布与人类数据相似 → 说明模型可能理解了决策机制
- 如果只在某些条件下相似 → 说明模型有局限性

### 6.3 模型恢复（Model Recovery）

**问题**：能否区分数据是由哪个模型生成的？

**方法**：
- 用分类器判断：给定问题特征，判断数据来自哪个模型
- 如果准确率高 → 说明不同模型的机制确实不同

### 6.4 内部表征对齐（RSA）

**问题**：LLM/神经网络内部是否真的"像"符号模型？

**方法**：
- 计算符号模型的潜变量（如 EU_diff, PT_diff）
- 计算神经网络/LLM 的内部表征
- 计算它们之间的相关性（RSA）

**解读**：
- RSA 高 → 说明内部表征相似，可能机制相似
- RSA 低 → 说明机制可能不同
